# Coffee Lovers Android App

Android WebView app for:

https://new.coffeelovers.shop/

## Build APK on GitHub

After uploading these files to the repository:

1. Open **Actions**
2. Open **Build Android APK**
3. Click **Run workflow** if a build did not start automatically
4. After completion, open the workflow run
5. Download artifact **CoffeeLovers-APK**
6. Extract the ZIP and install `app-debug.apk` on Android

Features:
- WooCommerce pages inside app
- Login/session cookies
- Cart and checkout
- File/image upload for payment receipts
- Android Back support
- External links open outside the app
